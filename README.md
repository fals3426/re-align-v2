# Re.align

Application Next.js (TypeScript) inspirée de Duolingo, centrée bien‑être.

## Démarrage

1. Installer les dépendances:
   - npm: `npm install`
   - yarn: `yarn`
   - pnpm: `pnpm install`

2. Lancer en dev:
   - `npm run dev`
   - ouvrir http://localhost:3000

## Structure

- `src/app/` — App Router (Next 13+)
- `src/app/page.tsx` — Page d’accueil
- `src/app/layout.tsx` — Layout racine + `globals.css`
